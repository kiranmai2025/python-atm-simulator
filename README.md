# ATM Terminal Simulator (Python CLI)

A command-line banking interface built with Python that simulates core ATM operations including authentication, balance inquiries, cash deposits, and withdrawals with input validation.

## Features
- **PIN Authentication:** Verifies security credentials before granting account access.
- **Balance Inquiry:** Displays current account balance.
- **Deposit Handling:** Accepts positive deposits and updates account balances in real time.
- **Withdrawal Validation:** Prevents invalid transactions (overdrafts and negative values).

## Concepts Demonstrated
- Standard User I/O (`input()`, `print()`)
- Data Types & Type Conversion (`int`, `float`, `str`)
- Relational and Logical Operators (`==`, `<=`, `>`, `and`)
- Conditional Decision Trees (`if`, `elif`, `else`)

## How to Run
1. Ensure Python 3 is installed.
2. Run the script from the terminal:
   ```bash
   python atm.py
